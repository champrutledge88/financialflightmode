# Funnel Evidence Classification

This directory contains sanitized public summaries only. Detailed operational evidence belongs in the approved private record.

## Approved Private Record

The Founder approved `docs/projects/core-funnel-reliability-gate/` in the Financial Flight Mode Launch Build project folder as the private record. This is unversioned local storage, and the Founder accepted its durability risk.

## Public Information Allowed

- Route paths and statuses
- CTA labels and targets
- Rendered consent string
- Git facts: branch point, branch, and deployed state
- Event names emitted
- Public source identifiers: `G-JXVRBKSSMH`, `2411474`, and `189897889621738735`
- Verification metadata
- Nonsensitive notes
- Private reference IDs

## Private Information Only

- MailerLite workflow ID and automation internals
- Subscriber identifiers, address, name, and activity
- GA4 property number, account structure, and Admin screenshots
- Full GA4 payloads
- Authenticated dashboard screenshots
- SPF, DKIM, and DMARC values
- Netlify deploy IDs and build logs
- Inbox screenshots and headers
- Unremediated weakness

## Prohibited From the Repository

Never commit API keys, tokens, secrets, passwords, session cookies, provider credentials, subscriber emails, raw user data, financial values, screenshots, or authenticated data.

## Reference IDs

Use `FFM-EV-YYYY-MM-DD-NN`. Public files carry an ID and PASS or FAIL result. Private records carry the details. Public rows that require private context must say `See FFM-EV-YYYY-MM-DD-NN`.

## Repository Visibility

Repository visibility is not a privacy control and must never be relied on as one.
